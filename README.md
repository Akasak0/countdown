# Countdown

macOSのスティッキーズみたいに、時間の付箋を置く小さなタイマー。現在はローカルで試すための0.1版です。

## 使う

`17:45` なら次に来る17:45まで、`3m` なら今から3分。Enterで開始します。

- 絶対時間：`9:5`、`17:45`、`9:5:3`、`17:45:30`。
- 相対時間：`3m`、`90s`、`1h30m`、`1h5s`。最大365日。
- 日付指定：「詳細…」で終了日時を選びます。過去の日時では開始しません。
- 空欄Enter：開いている窓で最後に確定した指定を再利用。すべての入力済み窓を閉じた場合は、最後に閉じた入力済み窓の指定を使います。
- ラベル欄：用途を自由に入力。時間とは独立して編集できます。

初期状態は最前面表示ON、背景の不透明度0.7、分表示。文字は透けません。
音・システム通知・紙吹雪・相対時間の一時停止は初期OFFです。

窓の「外観…」からその窓の色・背景の不透明度・最前面表示を変更できます。
⌘,の共通設定で、新しい窓の外観と、すべてのタイマーの表示単位・終了演出を設定します。
サイズは窓の端をドラッグするか、「表示」メニューのサイズ指定で変更します。

### キー操作

| 操作 | キー |
| --- | --- |
| 新規タイマー | ⌘N |
| 窓を閉じる | ⌘W |
| 最後に閉じたタイマーを復元 | ⇧⌘T |
| 最小化 | ⌘M |
| アプリを隠す | ⌘H |
| 設定 | ⌘, |
| 保存して終了 | ⌘Q |
| 開始 | 時間の入力欄でEnter |
| 実行中の時間変更を取り消す | 時間の入力欄でEsc |

コピー・ペースト・全選択・入力編集の取り消しにも対応します。
メニューの「ヘルプ → 使い方」から操作を確認できます。

### 閉じる・スリープ・復元

- 最小化・非表示・MacBookのスリープでも、締切は変わりません。
- 終了日時と現在時刻の差で計測します。スリープ中に終了した場合、復帰後は「終了しました」の表示だけで、音や演出を遡って再生しません。
- ⌘Q後の再起動では、開いていた窓の位置・サイズ・ラベル・指定・締切を復元します。
- 閉じた窓は直近30件まで復元可能。閉じた窓への通知は行わず、復元時に元の締切から残り時間を求めます。
- 一時停止は、設定で有効にした場合の相対時間のみ。再開すると終了日時が延びます。絶対時間には一時停止を適用しません。
- 一時停止機能をOFFにしても、すでに一時停止しているタイマーの「再開」は使えます。

設定とタイマーは `~/Library/Application Support/Countdown/state.json` に保存します。
読み込みに失敗した場合は元のデータを上書きせず、エラーを表示して終了します。

## ビルド

macOS 13以降を対象にしています。現時点でビルド・動作確認するのは手元のApple Silicon Macのみです。
Swift 6以降を含むXcodeまたはCommand Line Toolsを使います。外部パッケージはありません。

```sh
bash scripts/build-app.sh
open dist/Countdown.app
```

出力は `dist/Countdown.app`。ローカル用の署名を付けます。
友人へ配布するためのDeveloper ID署名・公証・別のMacでの起動確認は、まだ行っていません。

```sh
bash scripts/test.sh
```

テストでは入力の検証、翌日・夏時間の時刻解釈、保存と復元、スリープ相当の時間経過、
一時停止、履歴選択、終了演出の重複抑制、表示単位の丸めを確認します。
実際のスリープや通知の許可、見た目についてはGUIでの確認が別途必要です。
