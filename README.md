# Countdown

macOSのスティッキーズのように、時間の付箋を置く小さなタイマーです。
作業の邪魔をすることなく、作業の締切や、カップ麺などに使うことができます。

**開発中の試用版です。** まだバグや調整中のUIがあります。使ってみて気になったところを教えてもらえると助かります。

## できること

- `17:45` まで、`3m` 後、どちらもひとつの入力欄で指定。
- タイマーを複数の小窓で表示。ラベルを付けて好きな場所に置く。
- 色・背景の不透明度・最前面表示を変更。文字はくっきり、背景だけが透ける。
- 操作UIを隠して、小さく表示。Dock横の空きにも置ける。
- 分・時:分:秒・自動から時間の表示を選択。
- タイマーと窓の配置を保存し、次回起動時に復元。
- 終了時の音・通知・紙吹雪を個別に設定。
- ラベル付きのタイマーを順番に実行するオートメーション。名前の入力候補・GUI編集・JSON編集に対応。

## 試してみる

現在はソースからビルドして試す形です。配布用のアプリは準備中です。

### 必要なもの

- Mac。アプリの対象はmacOS 13以降です。
- Swift 6以降を含むXcodeまたはCommand Line Tools。

現時点で動作確認しているのはApple SiliconのMacです。Intel Macや別のmacOSでの動作は未確認です。

### ビルドして起動

このリポジトリを取得し、プロジェクトのフォルダで次を実行してください。

```sh
bash scripts/build-app.sh
open dist/Countdown.app
```

`dist/Countdown.app` が生成されます。外部パッケージのインストールは不要です。
ビルドしたMacで試すためのローカル署名を付けています。配布用のDeveloper ID署名・公証はまだ行っていません。

## 基本の使い方

1. 時刻か時間の長さを入力する。
2. 入力欄の下に出る終了日時を確認する。
3. Enterで開始。必要ならラベルを付けて、好きな場所に置く。

| 入力例 | 動作 |
| --- | --- |
| `17:45` | 次に来る17:45まで |
| `1234` | 次に来る12:34まで |
| `12` | 次に来る12:00まで |
| `0123` | 次に来る01:23まで |
| `0030` | 次に来る00:30まで |
| `9:5:3` | 次に来る09:05:03まで |
| `3m` | 今から3分 |
| `90s` | 今から90秒 |
| `1h30m` | 今から1時間30分 |
| `1h5s` | 今から1時間5秒 |

コロンなしの時刻は半角2桁で時、4桁で時分を指定できます。コロンありの時刻は左から時・分・秒で、秒を省略すると0です。今日の指定時刻が過ぎていれば明日になります。
時間の長さは半角整数と小文字の `h`・`m`・`s` を使い、最大365日まで指定できます。

- **空欄でEnter**：前回の指定を再利用。使われる指定は入力欄の下に表示されます。
- **数字をダブルクリック**：時間を変更。確定するまでは元のタイマーが進みます。
- **カレンダーボタン**：日付を含む終了日時を指定。
- **スライダーボタン**：その窓の色・不透明度・最前面表示を変更。
- **ラベル欄でEnter**：ラベルの編集を終了。

アイコンにポインタを置くと操作内容が表示されます。メニューバーからも操作できます。

### 小さく置いておく

⇧⌘U、または「表示 → 操作UIを隠す」で、残り時間とラベルだけの表示にできます。
ラベルが空なら時間だけになります。最小サイズは120×60ポイントです。

ドラッグで移動し、窓の端でサイズを変更できます。右クリックか⇧⌘Uで操作UIを戻せます。
小窓でも、数字をダブルクリックすれば時間の入力に戻れます。

### 設定

⌘,、または「Countdown → 設定…」から変更できます。

- 新しい窓の色・不透明度・最前面表示。
- 時間の表示：分／時:分:秒／自動。
- 相対時間の一時停止機能。
- 終了時の音・システム通知・紙吹雪。

初期設定は最前面表示ON、背景の不透明度0.7、分表示です。
音・通知・紙吹雪・一時停止機能は初期OFFです。
自動表示は「1日2時間」「1時間23分」「23分45秒」「45秒」のように切り替わります。

### オートメーション

⌘, の「オートメーションを作成・管理…」から、講義と休憩などのタイマーを順番に登録できます。
保存した名前をタイマーの入力欄に入れると開始します。名前の途中では候補が出るので、↑↓とEnterで選べます。

`10:30まで「講義」 → 10m「休憩」 → 90m「講義」` のように、時刻と時間の長さを混ぜられます。
スリープ復帰時は元の締切から現在の区間へ進み、全部過ぎていれば終了します。
実行中に設定を編集しても、そのタイマーには影響しません。終了後の空欄Enterは最新の設定で再実行します。

詳しい使い方・JSONのキーは [AUTOMATIONS.md](AUTOMATIONS.md) にあります。

### ショートカット

| 操作 | キー |
| --- | --- |
| 新規タイマー | ⌘N |
| 窓を閉じる | ⌘W |
| 最後に閉じたタイマーを復元 | ⇧⌘T |
| 操作UIの表示切り替え | ⇧⌘U |
| 最小化 | ⌘M |
| アプリを隠す | ⌘H |
| 設定 | ⌘, |
| 保存して終了 | ⌘Q |
| 開始 | 時間の入力欄でEnter |
| 時間変更を取り消す | 入力中にEsc |

コピー・ペースト・全選択・入力編集の取り消しにも対応しています。
使い方を忘れたら「ヘルプ → 使い方」から確認できます。

## 保存とスリープ

- 最小化・非表示・スリープ中も、タイマーの時間は進みます。
- スリープ中に終了した場合は、復帰後に終了表示を出します。音や演出を遡って再生しません。
- ⌘Qでは開いている窓を保存し、次回起動時に元の締切から復元します。
- 窓を閉じた場合は直近30件まで復元できます。閉じた窓への終了通知は行いません。
- 一時停止は、設定で有効にした場合の相対時間のみです。再開すると締切が延びます。
- 全部の窓を閉じてもアプリは残ります。⌘Nで新しい窓を開けます。

設定とタイマーは `~/Library/Application Support/Countdown/state.json` に保存します。
保存データが読めない場合は、元のファイルを上書きせずにエラーを表示して終了します。

## 不具合・UIの感想

このリポジトリの **Issues → New issue** から「不具合報告」か「UI・使い勝手の提案」を選んでください。
「ここがわかりにくい」「この操作が面倒」くらいの感想も歓迎です。
感想はX(旧Twitter)などで直接報告してもらっても大丈夫です。

不具合の場合は、次がわかると調べやすいです。

- 入力した値と、発生するまでの操作。
- 期待した動作と、実際に起きたこと。
- アプリのバージョン、macOSのバージョン、Apple Silicon／Intelのどちらか。
- スクリーンショットや短い動画があれば、それも。

特に、小窓の移動・サイズ変更、複数窓、スリープ復帰、保存・復元、通知まわりを試してもらえると助かります。

## 現在の制限

- まだ試用版です。時間の精度やUIを含め、改善を続けています。
- 別のMacでの起動、実機のスリープ復帰、OSの通知許可・配送には未確認の部分があります。
- スリープ中にMacを起こして通知する機能、自動更新はありません。
- Macの時計を手動で変えると、残り時間にも影響します。
- 自然文の日付、日本語の時間表記、2桁・4桁以外の単位なしの数値は解釈しません。

開発・テストの手順は [CONTRIBUTING.md](CONTRIBUTING.md)、内部の仕様は [DESIGN.md](DESIGN.md) にまとめています。
